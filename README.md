# xcVideoEdit

单轨无损剪辑 + 画面取景（裁切/等比缩放）+ 音频段落截取合一的桌面小工具。基于 Electron + ffmpeg，本地处理，不联网。

## 功能

**取景**

- 黑框是原始画面，红框是成片范围，拖红框即可改比例
- 8 个手柄拉伸、框内拖动移位，框外暗区会被裁掉
- 比例预设：原片比例 / 自由裁剪 / 16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 2.35:1 / 2:1 / 21:9
- 裁剪后再按百分比缩放：100% / 75% / 50% / 33% / 25% / 自定义
- 顶部实时显示最终输出尺寸，高度与百分比双向联动

**剪辑**

- 播放头定位，`C` 在当前位置切一刀，切点可逐帧微调
- 时间轴 + 片段列表，勾选/全选/全不选，点 `×` 删除切点与相邻片段合并
- 两种导出模式：
  - **无损快速**：`-c copy` 拷流，秒出片，但切点会吸附到最近关键帧，起点可能前后偏移
  - **精确重编码**：逐帧对齐，H.264 CRF 18 重编码，慢一些但切点准确

**一次导出**：按勾选片段切割 → 裁切 + 缩放 → 顺序拼接，输出单条 MP4。

**时间轴缩放 / 平移**：`Shift+滚轮` 以光标位置为锚点缩放，`Alt+滚轮` 左右平移，点击「显示全部」按钮（或双击时间轴、按 `Home`）一键回到完整片段；播放时播放头超出视图会自动跟随。缩放会同步作用到刻度、片段块、缩略图带和音频波形（放大后波形按像素重采样，不会拉伸失真）。

**撤销 / 重做**：`Ctrl+Z` / `Ctrl+Shift+Z`（也支持 `Ctrl+Y`）。覆盖切割、删切点、片段勾选、取景框拖动、比例/缩放/高度调整、导出模式切换；连续输入高度只记一条历史，单击红框不拖不会污染历史。

**工程文件**：`Ctrl+S` 保存为 `.xcproj`，`Ctrl+Shift+O` 打开。工程记录素材路径、切点、片段勾选、取景框、画面比例、输出高度与导出模式；首次保存弹选择框，之后 `Ctrl+S` 直接覆盖原工程。

**时间轴缩略图**：打开视频后自动抽 24 帧铺成缩略图带，点击任意一帧可跳到对应位置；按「路径 + 文件大小 + 修改时间」缓存，同一素材二次打开秒出。

**音频剪辑**

- 直接打开 mp3 / wav / m4a / aac / flac / ogg / opus / wma / aiff 等音频文件（也可直接拖进窗口）
- 预览区自动切换成波形视图：整段波形 + 播放光标，取景裁切控件自动隐藏
- 切割、勾选、`Alt` 单选、`Shift` 加选、逐段删除、进度显示与视频完全一致
- 导出格式按源文件走（mp3→mp3、wav→wav、flac→flac），也可在保存对话框改成 m4a / mp3 / wav / flac
- 无损模式直接拷流（切点对齐音频包，误差通常小于 0.05 秒）；目标容器与原编码不兼容时自动转码并提示

支持中文、空格、特殊字符的文件路径与文件名（盘符在自定义协议里会被 Chromium 误当作 host，已在 `lib/localpath.js` 里做了还原）。

## 启动

双击 `启动.bat`（直接调 electron.exe，无控制台窗口），或命令行：

```
npm install
node node_modules/electron/install.js
npm start
```

## 快捷键

| 操作 | 效果 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| `←` / `→` | 上一帧 / 下一帧（Shift 为 10 帧） |
| `C` | 在播放头切割 |
| 拖红框 | 移动取景范围；拖手柄改大小 |
| 双击红框 | 恢复原片比例并铺满画面 |

## 依赖

- Node.js 22+、Electron 45
- ffmpeg / ffprobe：默认 `F:\Tools\ffmpeg\bin`，可用环境变量 `XC_FFMPEG` / `XC_FFPROBE` 覆盖
- 编码：libx264（CRF 18，yuv420p）+ AAC 192k，MP4 输出

## 已知限制

- 无损模式下切点必须落在关键帧，源视频关键帧稀疏时偏移明显；需要准切点请用精确重编码
- 一旦启用裁切或非 100% 缩放，必须重编码，程序会自动从「无损快速」切到「精确重编码」
- 音频的「无损快速」按音频包边界切，误差通常 < 0.05 秒；需要严格对齐请用「精确重编码」
- 音频波形解析上限 400MB，超过后跳过波形但切割与导出不受影响
